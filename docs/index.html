What it does

Real double-entry bookkeeping, on your device. Every amount is an integer number of paise, because “reduces net worth by exactly ₹1,000” is a claim floating point cannot keep.

Net worth is never stored. It is derived from the transactions every time — a stored balance can disagree with the ledger; a derived one cannot.

What it refuses

A transaction that does not balance cannot be saved. No bank connection, ever. Repeat rules are listed, never posted by themselves.

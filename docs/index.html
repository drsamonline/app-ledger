Ledger

Real double-entry bookkeeping, on this device. A transaction that does not balance cannot be saved, and nothing ever connects to a bank.

Open Ledger

Every amount is an integer number of paise. “Reduces net worth by exactly ₹1,000” is a claim floating point cannot keep — so it does not use floating point.

Status Built and working offline: accounts of five types; transactions posted as debits and credits that must balance; a balance sheet whose totals agree with the sum of its own rows; an income/expense report whose net is income minus expense; budgets and repeat rules evaluated on device, with nothing posted by itself; and a full JSON export that re-imports with identical totals.
Release: Windows EXE, Android APK and Linux binary, built from this source in CI — app-latest.
Not built: reading a receipt photo. There is no OCR in this estate, so entries are typed — and the app says so rather than shipping a camera button that does nothing.

What it does

  • Posts proper double-entry transactions: debits equal credits, or nothing is saved.
  • Computes net worth as assets minus liabilities, from the ledger — never stored, always derived.
  • Reports a balance sheet and an income/expense statement, each checked against its own rows.
  • Keeps budgets and repeat rules, evaluated on device; a repeat is listed when due, never posted by itself.
  • Exports the whole ledger to a JSON file you own, and imports it back with identical totals.

What it will not do

  • Connect to a bank. There is no network code in the app at all — no fetch, no endpoint, CSP connect-src 'none'.
  • Save a transaction that does not balance. Both totals are shown instead.
  • Date an entry for you. No date is refused rather than dated today.
  • Merge duplicates. Two identical entries are both kept and flagged — merging would be a lie about the money.
  • Rebuild an unreadable ledger. A wrong balance is worse than no balance.
  • Post a repeat by itself. A ledger that posts by itself is a ledger you cannot trust.

When things go wrong

CaseWhat happens
Bad inputNo amount, an unparseable amount, no date, an impossible date, a zero amount, an unknown account — each refused, with the value shown.
No networkNothing changes, and that is the point: there are no bank connections, ever.
Storage full or unavailableThe entry is not saved and the app says the balance does not include it.
Corrupt saved stateReported and offered for export; never rebuilt from a partial read.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — the spec's countable done-means is asserted there, to the paisa.
